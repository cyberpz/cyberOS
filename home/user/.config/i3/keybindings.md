# i3 - Keybindings

## Aprire applicazioni
- `WIN + Invio` → Rofi (launcher app)
- `WIN + d` → Alacritty (terminale)
- `WIN + Shift + w` → Firefox
- `WIN + t` → Telegram (app desktop)
- `WIN + Shift + t` → Thunar (file manager)
- `WIN + Shift + s` → Flameshot (screenshot)
- `WIN + v` → Clipboard history (clipmenu, ultime 10 clip)

## Gestire finestre
- `WIN + frecce` → sposta focus
- `WIN + Shift + frecce` → sposta finestra
- `WIN + f` → fullscreen
- `WIN + Shift + spazio` → floating toggle
- `WIN + spazio` → focus mode toggle
- `WIN + q` → chiudi finestra
- `WIN + Shift + q` → kill finestra corrente
- `WIN + a` → focus parent

## Workspace
- `WIN + 1..0` → vai al workspace
- `WIN + Shift + 1..0` → sposta finestra nel workspace
- `WIN + Shift + -` → sposta finestra nello scratchpad
- `WIN + -` → mostra/nascondi scratchpad

## Layout
- `WIN + h` → split orizzontale
- `WIN + Shift + v` → split verticale
- `WIN + s` → layout stacking
- `WIN + w` → layout tabbed
- `WIN + e` → alterna layout

## Bordi finestre
- `WIN + b` → toggle bordo/title bar della finestra corrente

## Modalità resize
- `WIN + r` → entra in modalità resize
  - `frecce/hjkl` → ridimensiona
  - `Invio/Esc/WIN+r` → esci dalla modalità resize

## Reload / restart / uscita
- `WIN + Shift + c` → ricarica config
- `WIN + Shift + r` → riavvia i3
- `WIN + Shift + e` → esci da i3

## Media / luminosità / volume
- `XF86AudioRaiseVolume` → volume +
- `XF86AudioLowerVolume` → volume -
- `XF86AudioMute` → mute
- `XF86MonBrightnessUp` → luminosità +
- `XF86MonBrightnessDown` → luminosità -

## Altri
- `WIN + ?` → apre questo file
